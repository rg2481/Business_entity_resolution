# Business_entity_resolution
Built for Amazon ML Challenge 2026, this repo consists a high-performance Python pipeline matching 1.73M reference businesses to ~10M noisy records across 3 countries and 10 writing systems using GPU TF-IDF retrieval, a LightGBM pair model, and a multilingual transformer cross-encoder, achieving a 0.9822 F0.5 score with PyTorch.
